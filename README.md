# Парсер вакансий с сервера HH.ru с последующим сохранением в БД 
Программа, которая получает информацию о вакансиях с платформы hh.ru в России, сохраняет её в базу данных, в последующем выводит информацию о вакансиях и работодателях.  
## Установка:
Клонируйте репозиторий: git@github.com:gabdrakhmanov-D/A-job-parser-with-HH.ru-saved-in-the-database.git  
Обновите зависимости с помощью команды `poetry update`.  

## Использование:  
Для запуска программы необходимо запустить файл main.py.  
Например, это можно сделать с помощью командной строки, введя команду: python 'ПУТЬ К ФАЙЛУ'\main.py.  

Для загрузки вакансий, предварительно нужно создать json файл с id компаний на hh.ru и названием. Файл необходимо сохранить в директории `data`. 

Для подключения к БД используйте файл database.ini.example. Заполните все поля своими параметрами.  

Модуль config.py содержит ссылки на файлы database.ini и json файл с id компаниями. При необходимости измените пути к этим файлам, если вы хотите их открыть из другой директории.  

## Документация:
В пакете src есть следующие модули:

### - Модуль `creator_db.py`:
Модуль содержит класс `CreateDB`, он служит для создания базы данных с таблицами.  

### - Модуль `db_manager.py`:
Модуль содержит класс `DBManager` который рализует запросы к БД и выдаче таблиц с результатами.  

### - Модуль `employer_info.py`:
Модуль содержит класс `EmployerInfo` который необходим для хранения подробной информации о работодателе.  

### - Модуль `foundemployers.py`:
Модуль содержит класс `FoundEmployers` который необходим для хранения информации о найденных работодателях.  

### - Модуль `head_hunter_api.py`:
Модуль содержит класс `HeadHunterAPI` который делает запросы к серверу hh.ru.  

### - Модуль `save_vacancy_to_db.py`:
Модуль содержит класс `SaveVacancyToDB` который служит для сохранения вакансий и компаний в БД.    

### - Модуль `utils.py`:
Модуль содержит вспомогательные программы для работы с json и взаимодействия с пользователем.  

### - Модуль `vacancies.py`:
Модуль содержит класс `Vacancy` который служит для создания объектов вакансий.

### - Модуль `vacancy_parser.py`:
Содержит абстрактный класс `VacancyParser` для создания классов подключающихся к различным API.
